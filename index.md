# Extremal Graph Theory & Turán Numbers

Welcome to my curated repository of extremal bounds, asymptotic behavior, and structural theorems.

### Testing Inline Math
We can write a basic inline formula like $ex(n, C_4)$ or reference a specific clique index $K_r$. 

### Testing Display Math
For larger, centered equations, we can use standard double-dollar delimiters:

$$ex(n, C_4) = \frac{1}{2}n^{3/2} + o(n^{3/2})$$

When $n = q^2 + q + 1$ for a prime power $q$, the unique extremal graphs are derived from projective planes.
